# BCases Prizes Generator 🎁

Визуальный конструктор конфигурационных файлов `prizes.yml` для Minecraft плагина **BCases**. Создавай, редактируй и экспортируй сложные иерархии призов с удобным интерфейсом.

## ✨ Возможности

- 📦 **Управление кейсами**: добавляй, переименовывай и удаляй кейсы
- 🎯 **Редактирование призов**: шанс, зачарование, материал, отображаемое имя
- 📋 **Команды**: быстрая вставка команд через селект с плейсхолдерами
- 🔄 **Вложенные призы**: создавай подпризы любой глубины вложенности
- 📋 **Копирование призов**: дублируй призы со всей структурой команд и подпризов
- 📊 **Валидация**: автоматический подсчёт суммы шансов (зелёный при 100%)
- 💾 **Автосохранение**: все изменения сохраняются в `localStorage`
- 📤 **Импорт/Экспорт**: загружай существующие YAML и скачивай готовые конфиги
- 📋 **Копирование текстом**: экспорт YAML прямо в буфер обмена

## 🎮 Интерфейс

### Главное меню
- **Загрузить YAML** - импорт существующего файла `prizes.yml`
- **Предпросмотр** - просмотр текущей конфигурации в YAML формате
- **Скачать YAML** - экспорт в файл
- **Копировать текстом** - быстрое копирование YAML в буфер

### Управление кейсами
Каждый кейс содержит:
- ✏️ Редактируемое название
- 📊 Бейдж с суммой шансов (зелёный/жёлтый)
- ➕ Кнопка добавления призов
- 🗑️ Кнопка удаления кейса

### Редактор призов
Для каждого приза доступны:
- `Шанс` - числовое значение >0
- `Зачар.` - чекбокс enchanted
- `Материал` - выбор из datalist популярных материалов
- `Display name` - отображаемое имя предмета
- Быстрые команды с плейсхолдерами
- Textarea для списка give-команд
- Кнопки: копировать приз, удалить, показать/скрыть подпризы

## 📁 Структура экспортируемого YAML

```yaml
- name: "Пример кейса"
  prizes:
    - chance: 50
      enchanted: true
      material: "diamond"
      display_name: "&bАлмаз"
      give_commands:
        - "[MESSAGE] &aВы выиграли алмаз!"
        - "[CONSOLE] say Игрок %player% получил алмаз"
    - chance: 50
      enchanted: false
      material: "stone"
      display_name: "Булыжник"
      give_commands:
        - "[GIVE] %player% minecraft:cobblestone 64"
      items:  # вложенные подпризы
        - chance: 100
          material: "diamond"
          display_name: "Сюрприз!"
          give_commands: ["[MESSAGE] Ого, ты нашёл секретный приз!"]
